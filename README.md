Симулятор ИВЛ T1 — работа по Wi-Fi без интернета
=================================================

1. Положите папку на ноутбук (или NAS), подключённый к той же Wi-Fi сети,
   что планшет и телефон.
2. Запустите сервер:
   • macOS:   двойной клик по start-mac.command
              (или в Терминале: python3 server.py)
   • Windows: двойной клик по start-windows.bat
              (нужен Python 3 с python.org, галочка «Add to PATH»)
   • NAS / Docker:
       docker build -t t1sim .
       docker run -d --name t1sim --restart unless-stopped -p 8080:8080 t1sim
3. Сервер напишет адрес вида  http://192.168.1.25:8080/
   Откройте его на обоих устройствах, введите одинаковый код сессии,
   выберите «Аппарат ИВЛ» и «Пульт инструктора».

Если не подключается:
 • Брандмауэр на ноутбуке: разрешите входящие подключения для Python
   (macOS спросит при первом запуске — нажмите «Разрешить»).
 • Гостевые Wi-Fi сети и точки доступа с «изоляцией клиентов» не пускают
   устройства друг к другу — используйте обычную сеть или раздайте Wi-Fi
   с телефона/роутера центра.
 • Другой порт: python3 server.py 9000

Интернет не нужен. Без интернета шрифты заменяются системными — это нормально.
